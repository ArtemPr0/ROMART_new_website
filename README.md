# ROMART — новый сайт (Этап 1)

Статический HTML/CSS/JS сайт по макету Figma `ROMART_RU`. Готов к заливке в `public_html` на Reg.ru.

## Структура

- `index.html` — лендинг
- `uslugi/` — 8 страниц услуг
- `404.html` — страница ошибки
- `politika-konfidencialnosti.html`, `polzovatelskoe-soglashenie.html` — юридические страницы
- `css/main.css`, `js/main.js`
- `assets/` — изображения и иконки
- `.htaccess` — UTF-8 и `ErrorDocument 404`

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер из корня проекта:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Архив для Петра

Рядом с репозиторием лежит готовый zip: `../ROMART_new_website_stage1.zip` (~23 MB).

## Выкладка на Reg.ru

1. Загрузите **содержимое** этой папки (или распакованный zip) в `public_html` (FTP/SFTP или файловый менеджер).
2. Не создавайте лишнюю вложенную папку `ROMART_new_website` внутри docroot, если домен должен открывать сайт сразу.
3. Проверьте, что `.htaccess` загрузился (на Apache).
4. Пройдите чеклист: главная, услуги, форма «Заказать звонок», cookie, несуществующий URL → 404.
5. Пётр переключает `romart.ru` на этот хостинг.
6. Старая Тильда остаётся на `romart.info` (архив).

## Поведение Этапа 1

- Якоря: Клиенты / Кейсы / Отзывы / Контакты
- Cookie-баннер на всех страницах (`localStorage`)
- Формы открывают `mailto:zotova@romart.ru` (заглушка до CRM)
- Новости на лендинге — плейсхолдеры (архив = Этап 2)

## Шрифт

В макете — Involve. В сборке подключён веб-шрифт **Onest** (Google Fonts) как близкий аналог. Когда будут файлы Involve (`.woff2`), положите их в `fonts/` и обновите `@font-face` в `css/main.css`.
